# TravelTrucks

TravelTrucks is a camper rental web application built with Next.js and TypeScript.

The application allows users to browse available campers, filter them by different parameters, view detailed information, read reviews, and submit a booking request.

## Live Demo

[TravelTrucks](https://travel-trucks-kappa-teal.vercel.app/)

## Repository

[GitHub Repository](https://github.com/ClementineLavender/travel-trucks)

## Features

- Home page with a hero section and navigation
- Camper catalog with server-side filtering
- Filtering by:
  - Location
  - Camper type
  - Engine
  - Transmission
- Load more functionality for the camper list
- Camper details page with:
  - Image gallery
  - Camper information
  - Vehicle details
  - Reviews and ratings
- Booking form with client-side validation
- Booking request submission to the backend API
- Success and error notifications
- Loading states
- Error and not-found pages
- Responsive layout

## Technologies

- CSS Modules

## API

The application uses the TravelTrucks backend API:

`https://campers-api.goit.study`

The API is used to:

- fetch campers
- filter campers
- fetch camper details
- fetch reviews
- submit booking requests
